# NavigationBar
Barra de navegación flexible de M3 Expressive para la clase Compact (menos de 600 px).

- **Medidas:** 64 px de alto, la versión corta de M3 Expressive.
- **Destinos:** 4 principales más "Más", que abre una hoja inferior con Recursos y Soporte.
- **Superficie:** fondo `surface-container` e indicador `secondary-container`.
- **Ajuste:** respeta `env(safe-area-inset-bottom)` en celulares con barra de gestos.
